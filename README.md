## 📋 Descripción

Este es mi portfolio personal desarrollado con las últimas tecnologías web. Muestra mis proyectos más destacados, habilidades técnicas y experiencia como desarrollador frontend. El sitio está construido con un enfoque en la experiencia de usuario, animaciones fluidas y diseño responsive.

## ✨ Características

- 🎨 **Diseño Moderno**: Interfaz limpia y profesional con modo oscuro/claro
- 📱 **Totalmente Responsive**: Optimizado para todos los dispositivos
- ⚡ **Rendimiento Optimizado**: Construido con Next.js 15 para máxima velocidad
- 🎭 **Animaciones Fluidas**: Integración con Framer Motion
- 🎯 **SEO Optimizado**: Meta tags y estructura optimizada para motores de búsqueda
- 🔧 **Componentes Reutilizables**: Arquitectura modular con shadcn/ui
- 🎪 **Interactivo**: Efectos hover y transiciones suaves

## 🛠️ Tecnologías Utilizadas

### Frontend

## 🚦 Instalación y Uso

### Prerrequisitos
- Node.js 18+ 
- pnpm (recomendado) o npm

### Clonar el repositorio
```bash
git clone https://github.com/Fedeeherrera/FeDev.git
cd FeDev
```

### Instalar dependencias
```bash
pnpm install
# o
npm install
```

### Ejecutar en desarrollo
```bash
pnpm dev
# o
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

### Construir para producción
```bash
pnpm build
# o
npm run build
```

### Ejecutar en producción
```bash
pnpm start
# o
npm start
```
